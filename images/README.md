# 지도 참고 이미지

각 장소 폴더에 대표 이미지를 `main`이라는 이름으로 넣어 주세요.
확장자는 원본 그대로 사용하세요. PNG, JPG, JPEG, WebP를 지원합니다.

- `places/지역/장소/main.png`: 실제 장소 사진
- `factions/문파/main.png`: 문파나 세력 전용 그림
- 지역명 자체의 사진은 해당 지역의 `지역명-지역전경` 폴더에 넣습니다.
- 여러 지역에 걸친 강이나 산맥은 `places/광역`에 모았습니다.
- 소림사 등 산 이름과 함께 표시되는 문파는 해당 산 폴더를 사용합니다.
- 사진을 모두 채울 필요는 없습니다. 준비된 장소부터 넣으면 됩니다.
- 추가 사진은 같은 폴더에 `winter.png`, `temple.png` 등으로 넣어도 됩니다.

`image-map.json`에 현재 지도의 표시 이름과 예정 이미지 경로를 모두 기록했습니다.
이 파일은 관리용 목록입니다. 실제 표시 경로는 index.html의 각 지점에 있는 `data-image` 속성입니다.
연결된 사진은 장소를 클릭하면 오른쪽 설명창 안에 작게 표시됩니다.
같은 경로와 파일명으로 사진을 교체하면 코드 수정 없이 바뀝니다.
새 장소에 사진을 넣거나 확장자를 바꾸면 설명창 연결 작업을 요청해 주세요.

각 폴더의 `.gitkeep`은 빈 폴더를 Git에 보관하기 위한 빈 파일입니다. 그대로 두어도 됩니다.
GitHub 업로드 시 images 폴더는 index.html과 같은 위치에 유지하세요.
사진의 출처와 사용 허가는 credits.md에 기록해 주세요.
